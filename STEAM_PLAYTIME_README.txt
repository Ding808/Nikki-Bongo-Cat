Steam Bongo Cat playtime mode
=============================

Use StartPetWithStats.Steam.cmd when you want playtime to count on Steam's
official Bongo Cat app. You can run this launcher directly from the folder or
from a desktop shortcut; you do not need to add it as a separate non-Steam game.

This launcher asks Steam to run app id 3419430, then starts the stats overlay
in attach mode. Because Steam starts the official app, the time is recorded on
Bongo Cat itself instead of a separate non-Steam shortcut.

Requirements:
- Steam must be installed and signed in.
- Bongo Cat must be in your Steam library and installed.

Steam store Bongo Cat app id: 3419430.
