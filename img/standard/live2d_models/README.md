# Live2D 模型库使用说明

这个文件夹就是桌宠的 Live2D 模型库。每一个子文件夹代表一个可切换人物。

## 直接使用别人发来的模型文件夹

1. 把对方发来的整个 Live2D 模型文件夹复制到这里。
2. 打开统计浮窗里的「自定义桌宠」。
3. 在「基础素材」页点击「刷新 Live2D 模型列表」。
4. 在下拉框里选择人物，点击「应用选中模型并重启」。

模型文件夹里可以直接包含 `.model3.json`，也可以多包一层目录；程序会自动向下寻找有效的 Live2D 模型根目录。

## 一个有效模型至少需要

- 一个 `.model3.json`
- `.model3.json` 引用的 `.moc3`
- `.model3.json` 里 `Textures` 引用的 PNG 贴图

如果模型带有表情、动作、物理文件，也请一起保留原目录结构。

## 转发给别人

推荐在「自定义桌宠」里选择模型后点击「导出选中 Live2D 整包」，把导出的 zip 发给别人。这样会连同这个桌宠保存的触发键、基础素材和贴图一起打包。

也可以直接把这里的单个模型子文件夹发给别人；对方复制到自己的 `img/standard/live2d_models` 后刷新列表即可。
